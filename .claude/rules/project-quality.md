# Project Quality Rules

## Design

- clean;
- minimalista;
- editorial;
- premium;
- alta quantidade de espaço negativo;
- tipografia forte;
- composição antes de decoração.

Evitar excesso de cards, ícones, glow, gradientes, glass e padrões SaaS.

## Conversion

Cada seção deve ter uma função clara no funil:

```text
atenção
→ identificação
→ clareza
→ confiança
→ redução de objeções
→ ação
```

CTA principal: WhatsApp.

Não usar urgência falsa, escassez falsa ou prova social inventada.

## Motion

GSAP + ScrollTrigger são preferenciais.

Motion deve:

- orientar o olhar;
- reforçar storytelling;
- criar continuidade;
- preservar leitura;
- manter FPS.

Pins são permitidos quando melhoram narrativa.

Mobile pode usar experiência de motion diferente.

## Performance

Evitar:

- client component desnecessário;
- animação de layout;
- blur gigante;
- vídeo pesado acima da dobra sem estratégia;
- bibliotecas duplicadas;
- imagens sem otimização.

Medir impacto, não apenas supor.

## SEO

Toda alteração deve preservar:

- conteúdo rastreável;
- semântica;
- headings;
- metadata;
- sitemap;
- robots;
- canonical;
- performance;
- acessibilidade.

## Accessibility

Obrigatório:

- teclado;
- foco visível;
- contraste;
- reduced motion;
- labels;
- alt;
- semantic HTML.

## Data integrity

Nunca inventar:

- clientes;
- projetos;
- avaliações;
- resultados;
- estatísticas;
- parceiros;
- certificações.

Use placeholders claramente identificados quando necessário.
